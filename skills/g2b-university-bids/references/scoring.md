# 컨설팅 적합도 점수 기준

공고명 키워드로 1차 선별한다. 사전을 고칠 때는 `scripts/search_bids.py`의 `HIGH`, `HIGH_REGEX`, `MID`, `SI`, `EXCLUDE`, `NON_UNIV` 목록도 같이 고친다.

## 매칭 규칙

- 공고명의 띄어쓰기를 지운 뒤 비교한다. 예를 들어 "방안 수립"과 "방안수립"은 같은 것으로 본다.
- 영문 약어(AI, AX, DX, ISP, ISMP, BPR, RISE)는 **단어 단위로만** 매칭한다. KAIST 안의 'AI'는 매칭하지 않는다.
- '전략'은 '전략산업'(인력양성 사업명)일 때 매칭하지 않는다.
- '운영체계'는 제외어 '프로그램운영'·'운영지원' 판정에서 빼고 본다.

## 점수 계산

| 요소 | 점수 |
|---|---|
| 핵심 키워드 1개당 | +3 |
| 일반 키워드 1개당 | +1 |
| SI형 키워드 1개당 (핵심 키워드가 하나도 없을 때만) | −2 |
| 제외 키워드 1개당 | −5 |
| 예산 3억 이상 | +2 |
| 예산 1억 이상 | +1 |

## 등급

| 등급 | 점수 | 의미 |
|---|---|---|
| A | 5 이상 | 이번 주 바로 검토 |
| B | 2~4 | 관심 공고. 제안요청서 확인 후 판단 |
| C | 1 이하 | 비컨설팅 (시설·구매·행사·운영대행·SI 등). CSV에만 남김 |

- **일반(+1)**: 연구, 학술, 기획, 분석, 진단, 개선방안, 정보화, 플랫폼, 데이터, 스마트캠퍼스, AX, AI, DX, 인공지능, 디지털전환, 혁신, 글로컬, RISE, 라이즈, 앵커, 조사
  - 혁신·글로컬·RISE·앵커는 공고명 앞에 **예산 출처 태그**로 붙는 경우가 많아 +1로만 둔다.
- **SI형(−2)**: 시스템구축, 구축용역, 고도화, 솔루션, 개발용역
- **제외(−5)**
  - 시설: 청소, 경비, 미화, 시설관리, 공사, 감리, 수선, 보수, 유지관리, 유지보수, 조경, 전기안전, 승강기, 냉난방, 환경조성, 실습실, 안전점검, 시설검사, 인허가
  - 구매·지원: 급식, 식당, 구매, 임차, 렌탈, 인쇄, 운송, 버스, 운행, 보험, 번역, 숙식, 방역, 소독, 폐기물
  - 행사·운영대행: 대행, 행사, 축제, 축전, 페스티벌, Festival, 박람회, 공유회, 성과발표회, 컨퍼런스, 세미나, 학술대회, 전시, 부스, 연수, 인턴십, 벤치마킹, 캠프, 경진대회, 공모전, 챌린지, 해커톤, 메이커톤, 프로그램운영, 교육운영, 운영지원, 위탁운영, 운영위탁, 현장운영
  - 병원·연구지원: 세탁, 린넨, 위탁검사, 검진, 콜센터, 채용, 회계감사, 결산, 정산, 특허, 합성, 시험법, 부품, 조립, 프로토타입
  - 제작: 촬영, 영상, 콘텐츠

## 대상 기관

- 수요기관명 검색어: `대학`, `과학기술원`
- 제외 기관(`NON_UNIV`): 한국해양과학기술원 및 부설기관. '과학기술원' 검색에 잡히지만 대학이 아님

## 중복 제거

1. 같은 공고번호는 최신 차수만 남긴다 (정정공고).
2. 번호가 달라도 공고명과 수요기관이 같으면 가장 최근 공고만 남긴다 (재공고).

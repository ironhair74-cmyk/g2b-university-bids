# 컨설팅 적합도 점수 기준

공고명 키워드로 1차 선별한다. 사전을 고칠 때는 `scripts/search_bids.py`의 `HIGH`, `MID`, `EXCLUDE` 목록도 같이 고친다.

## 점수 계산

| 요소 | 점수 |
|---|---|
| 핵심 키워드 1개당 | +3 |
| 일반 키워드 1개당 | +1 |
| 제외 키워드 1개당 | −5 |
| 예산 3억 이상 | +2 |
| 예산 1억 이상 | +1 |

## 등급

| 등급 | 점수 | 의미 |
|---|---|---|
| A | 5 이상 | 이번 주 바로 검토 |
| B | 2~4 | 관심 공고, 제안요청서 확인 후 판단 |
| C | 1 이하 | 비컨설팅 (시설·구매 등). CSV에만 남김 |

## 키워드 사전

- **핵심(+3)**: 중장기, 발전계획, 발전전략, 전략수립, 컨설팅, ISP, ISMP, BPR, AX, AI, 인공지능, 디지털전환, DX, 혁신, 글로컬, RISE, 라이즈, 구조개혁, 재정, 조직진단, 경영진단, 타당성, 마스터플랜, 로드맵, 평가, 인증, 대학기관평가, 성과관리, 정책연구
- **일반(+1)**: 연구용역, 학술용역, 용역, 기획, 설계, 분석, 진단, 개선방안, 정보화, 플랫폼, 데이터, 스마트캠퍼스
- **제외(−5)**: 청소, 경비, 미화, 시설관리, 급식, 식당, 공사, 감리, 수선, 보수, 유지관리, 유지보수, 구매, 임차, 렌탈, 인쇄, 운송, 방역, 소독, 폐기물, 조경, 전기안전, 승강기, 냉난방, 통학버스, 보험, 행사대행, 번역

## 구분(트랙) 태그

- 기관명에 병원·의료원·보건 → `의료(대학병원)`
- 국립·서울대·과학기술원 → `국립대`
- 그 외 → `대학`
